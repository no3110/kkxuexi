# 订单流与价格行为学习系统

在线学习：https://no3110.github.io/kkxuexi/

这是已经构建好的静态网站部署仓库。根目录的 index.html 为入口，assets/ 为课程、图表与模拟实战所需资源，不需要安装依赖或运行后端。

## 使用说明

- 49 课中文知识讲解、分镜课件与语音播放、知识测验、学习记录，以及 MNQ/MGC 模拟实战考核。
- 分镜课件逐句语音讲解：可暂停 / 继续播放 / 重播本页，记住上次听到的位置；每页图文配合（概念示意图、本课 K 线例图、表格、对比、流程）。
- 全屏学习：图表铺满屏幕，讲解与全屏期间保持屏幕常亮；手机可一键横屏（不支持锁定方向的浏览器会把内容旋转 90°）。
- K 线图操作：拖动 K 线区域平移，滚轮 / 双指缩放，上下拖价格轴、左右拖时间轴拉伸，双击或点右下角「复原」。
- 无需注册登录；学习进度、测验记录、模拟交易与 AI 设置保存在访问者自己的浏览器。更换浏览器、访问地址或清除网站数据不会保留这些记录。
- AI 功能采用 OpenAI 兼容接口，默认连接 DeepSeek。访问者自行填写接口、模型和密钥；网站未附带任何密钥。浏览器直连要求接口允许跨域请求。生成与复盘时，相应训练数据会发送给所选 AI 服务商。
- 本地和 AI 情景驱动的模拟行情均为合成教学数据，不是交易所实时或逐笔历史行情，不代表真实成交或未来表现。课程中的必要历史案例资源随站点保留。
- deploy-check.html 用于检查静态资源是否完整上传。

## 发布

发布分支为 main，GitHub Pages 从仓库根目录读取。只上传 dist 内层内容，确保 index.html 和本文件直接位于根目录。无构建工作流，不需要修改 Pages 或 HTTPS 设置。

此目录不包含开发文档、测试输出、个人交易记录、浏览器存储、环境配置或凭据文件。
